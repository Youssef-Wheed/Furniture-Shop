# Furniture Shop App

A modern and elegant Flutter application designed for a premium furniture shopping experience. This project serves as a comprehensive example of building a multi-screen retail app with a focus on UI/UX.

## 🚀 Features

- **Onboarding Experience**: A smooth introductory flow to welcome users to the shop.
- **Home Screen**: A curated display of furniture categories and featured products.
- **Custom UI Components**: Reusable widgets like `CustomText` for consistent styling.
- **Typography**: Integrated with `Google Fonts` for a high-quality visual feel.

## 📂 Project Structure

```text
lib/
├── Pages/
│   ├── onboarding.dart  # Entry point/Introduction screen
│   └── homepage.dart    # Main shopping interface
├── Widgets/
│   └── CustomText.dart  # Reusable stylized text component
└── main.dart            # App configuration and entry point
```

## 🛠️ Tech Stack & Dependencies

- **Framework**: [Flutter](https://flutter.dev/)
- **State Management**: Built-in `StatelessWidget` and `StatefulWidget`
- **Fonts**: [google_fonts](https://pub.dev/packages/google_fonts)
- **Icons**: [Cupertino Icons](https://pub.dev/packages/cupertino_icons)

## 🏁 Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
- [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/) with Flutter extensions.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/furniture_shop_app.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd furniture_shop_app
   ```

3. **Install dependencies**:
   ```bash
   flutter pub get
   ```

4. **Run the app**:
   ```bash
   flutter run
   ```
